Documentation Roadmap - 文档更新推进清单#

本章节用于承接后续文档更新工作. 后续 agent 应按本清单逐步推进, 只有完成源码对照、文档更新、生成验证后, 才能将对应条目标记为 [x].

Agent 工作规则#

  • [ ] 更新前先确认上游源码版本, 不要只按旧文档或记忆补写.
  • [ ] 每个页面必须回链到具体源码路径, 至少包含模块入口、主要方法、参数、返回值、关键限制.
  • [ ] 涉及运行时注入对象时, 必须对照 ScriptRuntime.kt 的 augment(...) 注册情况.
  • [ ] 涉及类型或选项时, 必须对照实现类、NativeObject 包装类、数据转换逻辑.
  • [ ] 修改 api/*.md 后, 同步更新 api/toc.md, api/sidebar.md, api/all.md, api/progress.md 和必要的 api/changelog.md.
  • [ ] 每轮完成后重新生成 docs/*.html 与 json/*.json.
  • [ ] 每轮完成后运行空白检查与关键内容检索, 并记录残留风险.

  • [x] 新增 MIME 基础页, 覆盖 MIME 字符串解析结果.
  • [x] 新增 NanoID 基础页, 覆盖随机 ID 生成能力.
  • [x] 新增 Sysprops - 系统属性 基础页, 覆盖系统属性读取与过滤.

  • [x] 更新 HTTP, 补充 6.7.0 异步请求、HEAD / PUT / DELETE, 响应体流式保存与请求选项.

  • [x] 更新导航、全量文档、部署进度、更新日志和静态 HTML / JSON 输出.

仍需优先补齐#

P0: 本轮新增基础页的完整化#

  • [x] SQLite: 已在现有页面补全 Database 主要方法, 校对 insert, update, delete, transaction, rawQuery, query 的完整签名、异常与示例.
  • [x] SQLite: 已在现有页面补全 CursorWrapper, 校对游标生命周期、自动关闭行为和字段类型映射.
  • [x] Zip: 已在现有页面补全 ZipOptions, ZipNativeObject, 校对 Zip4j 选项枚举、密码、加密、符号链接、覆盖写入行为.
  • [x] MediaInfo: 已补全 MediainfoNativeObject 动态属性、固定 stream 函数、字段解析、关闭释放边界和异常条件.
  • [x] MIME: 已补全 JsMime 返回结构、扩展名推断边界、宽松 MIME 字符串处理与异常条件.
  • [x] HTTP: 已校对 request, buildRequest, post, postJson, postMultipart, 移除旧 Auto.js 4.x 过时说法.
  • [x] HTTP: 已在 HttpResponseBody 补充 HttpSaveResult 完整字段、成功/失败 code 与关闭行为.
  • [x] Pinyin: 已对照 PinyinCore.kt 补齐选项、格式枚举、多音字、分词、姓氏模式和占位方法边界.
  • [x] Pinyin4j: 已对照实现补齐兼容 API、格式参数、默认值、别名、返回结构和错误边界.
  • [x] Cvt / Fmt: 已补充字节单位转换边界、大小写、空格、非法输入、AUTO 和 HALF_UP 四舍五入规则.

P1: 高价值既有页面源码校对#

  • [ ] Global - 全局对象: 对照全局函数、全局类、legacy 兼容项.
  • [ ] Automator - 自动化: 对照自动化动作、RootAutomator、无障碍桥接限制.
  • [ ] UiSelector - 选择器: 对照选择器方法、过滤条件、链式调用和兼容别名.
  • [ ] UiObject - 控件节点: 对照控件属性、动作、查找方法和回收/刷新行为.
  • [ ] App - 通用应用: 对照 Intent、启动、卸载、应用信息、权限相关方法.
  • [ ] AutoJs6 - 本体应用: 对照版本、构建信息、项目/脚本入口能力.
  • [ ] Device - 设备: 对照设备信息、亮度、音量、电池、屏幕、剪贴板能力.
  • [ ] File - 文件: 对照路径解析、读写、移动复制、递归、编码和权限边界.
  • [ ] Engine - 引擎: 对照脚本执行、引擎枚举、停止、事件与隔离行为.
  • [ ] Task - 任务: 对照定时任务、广播/Intent、持久化与 Android 版本限制.
  • [ ] UI - 用户界面: 对照 UI DSL、组件、事件、线程要求和生命周期.
  • [ ] Floaty - 悬浮窗: 对照权限、窗口类型、坐标、关闭与 Android 版本限制.
  • [ ] Web - 万维网: 对照 WebView 注入、WebSocket、客户端配置.
  • [ ] OCR - 光学字符识别: 对照 MLKit / Paddle / Rapid OCR 能力、选项与模型限制.
  • [ ] Notice - 消息通知: 对照通知渠道、构建器、权限和 Android 版本差异.
  • [ ] Console - 控制台: 对照日志、格式化、计时、悬浮控制台和构建选项.

P2: 类型页与知识库结构化#

  • [ ] 为高频类型补齐独立页面: ZipOptions, ZipNativeObject, Database, CursorWrapper, HttpSaveResult, JsMime, MediainfoNativeObject.
  • [ ] 为所有运行时注入模块建立机器可读索引: 模块名、版本、源码路径、方法名、参数、返回值、示例.
  • [ ] 为所有页面补充 "源码依据" 小节, 便于知识库回答时回链权威来源.
  • [ ] 为权限敏感能力补充 Android 版本、权限、Shizuku/Root/无障碍依赖.
  • [ ] 清理旧 Auto.js 4.x 文档残留, 标记 AutoJs6 中已删除、替换或行为变化的 API.
